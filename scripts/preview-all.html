Just Concentrate — All States

Popup · 360px toolbar dropdown
Idle
Default state when no focus session is running. Shows armed schedule count, duration picker, and quick-block for current tab.
Active Session
Shown when user starts a focus session (25 min / 1 hr / 2 hr). Displays countdown timer, progress bar, blocked site count, and end-early button.
Blocked Page · replaces blocked site navigation
Default
Shown when user navigates to a blocked site. Displays the domain, which schedule blocked it, countdown to unlock, and a "Go Back" action.
Escape Actions
Shown when user clicks "Need to get in?" on the default blocked page. Offers three override options: snooze (5 min break), allow permanently, or end the block early. Shows weekly override count as a gentle nudge.
Passphrase Challenge
Shown when friction level is set to "passphrase" and user picks an escape action. Must re-type their commitment phrase exactly to proceed. Progress bar shows match percentage. Paste is disabled.
Cooldown
Shown after passphrase is matched and user chose "end block early", or when friction is "wait" mode. A timed countdown (default 30s) forces a pause before confirming. Can cancel to stay blocked.
Onboarding · first-run flow · 3 steps
Step 1 — Templates
Shown on first install. User picks a preset schedule (Work Focus, Bedtime, Deep Work) or starts from scratch. One click creates a schedule with bundled site lists.
Step 2 — Commitment Phrase
After choosing a template. Optional — user sets a phrase they'll re-type to override blocks. Adds friction to make impulse overrides harder. Can skip.
Step 3 — Confirmation
Final step. Shows what was set up: schedule count, blocked sites count, and whether a phrase is active. Links to full settings page.
Options · Schedules
Schedules Tab
Main settings view. Lists all blocking schedules with day pills, time ranges, type (block/blackout/redirect), and armed/paused toggles. Disabling an active schedule requires passphrase if friction is enabled.
Options · Allowed Sites
Allowed Sites Tab
Global allowlist — these domains are never blocked, even during blackout mode. For essential tools like email, banking, and work apps. Keeps the list short to avoid loopholes.
Options · Usage
Usage Tab
Local-only focus insights. Shows blocks, snoozes, and overrides for today and this week. Coaching nudges surface patterns (e.g. "twitter.com pulled you back 26 times this week"). All data stays on device.
Options · Site Lists
Site Lists Tab
Reusable collections of sites that can be attached to any schedule. Edit a list once and every schedule using it updates. Bundled presets (Social Media, News, Streaming) are created during onboarding.
Options · Settings
Settings Tab
Commitment phrase, friction level (none / wait / passphrase), cooldown duration, Chrome sync toggle, and data export/import.
